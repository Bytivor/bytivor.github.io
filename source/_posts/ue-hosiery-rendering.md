同样是一层黑色织物，直接把皮肤染黑，看起来像紧身裤；把透明度降低，又容易像蒙了一层灰玻璃。近看能读出细密织纹，镜头一拉远，纹理却开始闪烁。高光调亮之后有了“亮丝”的感觉，但稍微转动灯光，表面又变成了塑料。

这些问题并不来自同一个参数。丝袜的颜色来自纱线与底层皮肤的共同作用，疏密来自纱线覆盖和拉伸，光泽来自微结构的方向性，远景稳定性则取决于一个像素里究竟装下了多少根纱线。要把效果做稳，需要先分清结构，再选择 UE 的材质与渲染路径。

这篇文章以游戏角色为目标，建立一套可以扩展的工作方法：**贴肤细织物优先身体合成，真实镂空交给覆盖与几何，离肤薄片再讨论透射。** 薄黑、肤色、白色、厚织、亮丝、网袜、蕾丝，以及接缝、湿润和破损，都从这套方法展开。

## 01 / 范围、版本与可交付内容

本文讨论的是实时角色材质，不进行纤维级路径追踪，也不提供某款游戏内部 Shader 的复刻结论。材料名称没有严格的一对一渲染模型：同样标为“丝袜”的商品，可能使用不同聚合物、织法、表面处理和弹力结构。

工程基线分成两组：传统 Material 工作流用于解释清晰、可迁移的 Opaque / Masked / Thin Translucent 接线；Substrate 单独解释真实层次与近似合并的区别。按 UE 5.8 文档核对功能，但老项目应以自身版本、RHI 和目标平台为准。UE 5.8 的新项目默认启用 Substrate，旧项目升级的配置可能不同，不能只按版本号判断当前材质系统。

代码是面向 Material Custom 节点的教学实现，附带 CPU 数学检查；**尚未在 UE 工程中编译或测量 GPU 性能**。因此本文给出复现步骤、预期变化和验证方法，不把理论结果写成实测帧率。

## 02 / 把“所有类型”拆成四个独立维度

不要建立一个含几十个开关的万能材质。先记录四个维度：纱线覆盖多少表面、纱线如何吸收光、纱线如何反光、织物是否与皮肤分离。商品分类可以很多，着色问题却能按这些维度组合。

| 外观类别 | 主要视觉特征 | 优先结构 | 最容易做错的地方 |
| --- | --- | --- | --- |
| 薄透黑 / 烟灰 | 肤色透出，掠射方向更密 | 身体 Opaque 合成 | 把颜色压黑当成全部效果 |
| 裸色 / 彩色薄袜 | 底层肤色与有色纱线混合 | 身体 Opaque 合成 | 对所有肤色使用相同最终底色 |
| 白色半透袜 | 纱线漫反射明显，底层仍可见 | 身体合成或高级分层 | 只增加透明度，导致灰玻璃感 |
| 厚织 / 天鹅绒感 | 低透射、较宽反射或绒面响应 | Opaque，必要时 Cloth / Fuzz | 强行保留明显透肤 |
| 亮丝 / 油亮整理 | 方向性高光和较窄反射瓣 | Opaque + 各向异性 | 把 Metallic 拉满 |
| 包芯丝 / 混纺 | 多种纤维响应共存 | 分区参数或多瓣近似 | 用单一 Roughness 解释全部光泽 |
| 渔网 / 大孔网袜 | 孔洞可辨认，边缘独立 | Masked 袜壳 + 皮肤 | 用半透明黑片代替孔洞 |
| 蕾丝 / 刺绣 | 花纹面、细线、孔洞混合 | Masked；近景补几何 | 远景花纹因阈值突然消失 |
| 印花 / 提花 / 条纹 | 染色变化或织密变化 | 颜色遮罩与结构遮罩分开 | 把印花全部做成凹凸 |
| 金银丝 / 亮片 | 局部导体或片状反射 | 局部材质分区 | 整条袜子都使用金属反射 |
| 薄纱袜口 / 离肤片 | 能看到背景与多层重叠 | 受控 Translucent | 忽略排序和速度信息 |
| 乳胶 / 涂层外观 | 连续膜层、较强表面反射 | 涂层或独立材质 | 把乳胶参数当作普通尼龙 |

长筒、连裤、短袜主要改变区域遮罩和几何结构，不一定改变基础 BRDF。袜口、脚尖、脚跟、裆部、接缝和加固片则常有不同织密、厚度或材质，应作为独立区域处理。

Denier（D）表示纱线的线密度，即 9000 米纱线的质量克数。它不是透明度，也不是成品织物的毫米厚度。20D 与 80D 可以帮助建立产品分组，但不能直接写成 `Opacity = D / 100`。相同 D 数在不同织法、颜色、拉伸和照明下，视觉结果可以明显不同。

## 03 / 先选管线，再做主材质

<figure class="face-figure"><img src="/img/hosiery/pipeline.png" alt="贴肤、镂空、离肤三种结构对应的 UE 材质路线" loading="lazy"><figcaption>图 02 · 结构决定管线。这里的 ForwardShading 透明照明模式，不等于把整个项目切换为 Forward Renderer。</figcaption></figure>

### A. 身体上的 Opaque 合成：大多数贴肤细袜的起点

直接在身体表面，或紧贴身体且完全遮住身体的袜区域，计算皮肤与纱线的颜色和材质参数。底层皮肤来自同一 UV 对应的贴图，并不是从 SceneColor 读取。

这种方法不会真的透过几何体，但视觉上可以表现“透肤”。它能沿用不透明表面的深度、速度和阴影流程。局限也很清楚：皮肤和纱线被压缩为一个有效表面，无法同时独立求解两层完整的反射与散射。

如果角色的裸露皮肤必须保留 Subsurface Profile，而袜区域需要 Default Lit 各向异性，可以划分材质区域或使用独立材质槽。传统系统中的逐像素 Shading Model 选择，不等于在同一个像素里连续混合两套完整光照模型。

### B. Masked 袜壳：孔洞需要真的露出皮肤

为网袜或蕾丝建立独立袜壳，皮肤网格保留在下面。覆盖贴图中纱线区域通过测试，孔洞区域丢弃像素，露出后方皮肤。这里的 Opacity Mask 是覆盖判定，不是纱线的吸收系数。

袜壳与身体应共享可靠的蒙皮和相近的变形结果。用模型尺度检查微小间隙，避免穿插与 Z-fighting；不能凭固定厘米数适配所有角色。袜口厚度、接缝和近景粗线可加几何，普通细针织没有必要逐根建模。

### C. Translucent 薄层：为真实分离保留预算

当布片离开皮肤，或必须看到它后面的场景，单表面合成便不够。传统材质可从 `Translucent + Thin Translucent + Surface ForwardShading` 开始，并用 Thin Translucent Material Output 输入有色透射。

薄层模型不自动生成织孔、纤维散射或多层排序。双腿交叠、与头发和粒子交叉、景深及运动拖影都需要单独验收。不要仅为“丝袜”这个名称就把整条腿做成透明层。

## 04 / 统一变量：覆盖、光学厚度和反射

<figure class="face-figure"><img src="/img/hosiery/cross-section.png" alt="皮肤与纱线的横截面说明覆盖、透射和反射的区别" loading="lazy"><figcaption>图 03 · 光线可以穿过孔隙、进入纱线后被吸收，也可以在纱线表面反射。三件事需要分别控制。</figcaption></figure>

设 `C` 是一个像素足迹内纱线的投影覆盖率，范围为 0～1；`TauRGB` 是纱线沿基准方向的无量纲光学厚度；`Ng` 是不包含微织纹的宏观法线；`V` 是表面指向相机的单位向量。

```text
mu       = max(abs(dot(Ng, V)), MuFloor)
T_thread = exp(-TauRGB / mu)
T_eff    = (1 - C) + C * T_thread
Base     = SkinColor * T_eff + YarnColor * (1 - T_eff)
```

`MuFloor` 防止掠射方向无穷放大。它是稳定和艺术控制参数，不是材料常数。先取 0.15，再用轮廓测试调整。`TauRGB` 越大，对应通道穿透越少；有色吸收的参数不能直接等同于“纱线 RGB 颜色”。

最后一行是 Opaque 路线的**有界颜色近似**，不是完整的双层辐射传输方程。它不包含独立皮肤光照、纱线多次散射和完整能量交换。对于白色纱线，表面反射往往很重要，不能仅调透射就期待得到真实白袜。

三个边界可以检查实现是否合理：`C = 0` 时回到皮肤；`TauRGB = 0` 时回到皮肤；`C = 1` 且光学厚度很大时趋向纱线颜色。在输入颜色为非负且有界时，输出也应处于两者之间。

<figure class="face-figure"><img src="/img/hosiery/transmission.png" alt="不同光学厚度和覆盖率下的透射率角度曲线" loading="lazy"><figcaption>图 04 · 左图固定覆盖率，右图固定光学厚度。曲线在极端掠射方向变平，是 MuFloor 限制的结果。</figcaption></figure>

### 为什么不直接用 Fresnel 把边缘染黑

菲涅耳反射描述界面反射随角度的变化。普通非金属通常在掠射角反射更强，它本身不是“边缘发黑”的公式。丝袜的轮廓变密可能来自投影纱线覆盖、纱线路径长度、皮肤底层可见性和艺术处理。

可以用 `pow(1 - saturate(dot(Ng,V)), p)` 做边缘密度调节，但应命名为 `EdgeDensity`，不要把它当作真实菲涅耳。先调光学厚度路径项，再决定是否需要额外覆盖变化；同时把两者拉满，很容易重复加深。

用于密度的宏观法线应与微织纹法线分开。否则每一根法线凹凸都在改变透肤，画面会出现脏点和运动噪声。

| Yarn Color / 染色贴图 | 纱线颜色，不包含灯光 | sRGB 开启 | YarnColor |

八张下载贴图不包含 Skin BaseColor 和 Yarn Color，后两者来自角色资产或材质参数。练习包的 Reinforcement 是沿 V 分布的示例，不会自动匹配脚尖或袜口。

## 06 / 第一个主材质：15 分钟搭起薄透黑袜基线

先建立一个平面和一个圆柱测试物，确保 UV 的 U 绕周向、V 沿长度。给底层使用一个中间亮度的肤色常量，暂时不用复杂皮肤纹理。这样可以看到材质变量，而不是被模型细节分散注意力。

传统材质设置为 Surface、Opaque、Default Lit。建立以下参数：`SkinColor`、`YarnColor`、`Coverage`、`TauRGB`、`MuFloor`、`Roughness`、`Anisotropy`、`NormalStrength`。关闭不必要的 Two Sided；实体圆柱和正常朝外的袜面不需要默认双面。

<figure class="face-figure"><img src="/img/hosiery/wiring.png" alt="Opaque 袜类材质的输入到输出接线地图" loading="lazy"><figcaption>图 06 · 基线材质的功能分组。图中每一行是一组依赖，不代表 UE 节点的逐引脚截图。</figcaption></figure>

在材质里放入 Custom 节点，Output Type 选 `CMOT Float 3`，按下表创建输入。将代码文件中的函数体直接粘贴进 Code 字段，不要额外包一层函数声明。

| Custom 输入 | 类型 | 接线 |
| --- | --- | --- |
| SkinColor | float3 | 皮肤颜色纹理 RGB 或 Vector Parameter |
| YarnColor | float3 | 纱线颜色参数 |
| Coverage | float | 0～1 覆盖率；基线先用常量 0.65 |
| TauRGB | float3 | 光学厚度；基线先用 `(0.28,0.28,0.28)` |
| MacroNormalWS | float3 | VertexNormalWS，或不含微织纹的世界空间法线 |
| ViewWS | float3 | CameraVectorWS |
| MuFloor | float | 0.15 |

```hlsl
float3 N = MacroNormalWS / max(length(MacroNormalWS), 1e-6);
float3 V = ViewWS / max(length(ViewWS), 1e-6);
float mu = max(abs(dot(N, V)), clamp(MuFloor, 0.02, 1.0));
float3 opticalDepth = min(max(TauRGB, 0.0) / mu, 80.0);
float3 T = 1.0 - saturate(Coverage)
         + saturate(Coverage) * exp(-opticalDepth);
return lerp(YarnColor, SkinColor, T);
```

输出连接 Base Color。Metallic 设 0，Specular 先保持默认，Roughness 先取 0.44，Normal 暂不连接，Anisotropy 暂设 0。第一轮只旋转圆柱或相机，观察角度密度；第二轮只旋转灯光，确认高光不是被画死在底色上。

随后把 `TauRGB` 乘上 Density 和 Reinforcement 的倍率，并使用独立参数控制倍率。加固区可以增加光学厚度，但不要同时无条件把覆盖、深色、AO、粗糙度全乘一遍。

最后才加入弱微法线与方向性。材质参数中的颜色应在线性空间运算；从 sRGB 纹理采样得到的颜色由引擎完成相应转换，不能在 Custom 里再随意做一遍 Gamma。

## 07 / 各向异性：先确认方向，再调光泽

纱线和编织结构会让不同方向的反射宽度不同。各向异性解决的是方向性，不直接决定透明度，也不意味着表面一定很光滑。针织线圈的局部方向会弯曲，不能把所有丝袜理解成平行直丝，更不能把斜纹丝绸公式无条件搬过来。

<figure class="face-figure"><img src="/img/hosiery/tangent.png" alt="同一椭圆高光瓣旋转零度四十五度和九十度" loading="lazy"><figcaption>图 07 · 方向场旋转的示意。高光具体形状仍由模型、灯源形状、粗糙度和观察方向共同决定。</figcaption></figure>

对传统 Default Lit 路线，优先使用引擎自带的 Anisotropy 与 Tangent 输入。先用一根常量切线做方向对照，再接 Flow 贴图；不要一开始就把自定义 BRDF 写进 Emissive。

将 Flow 的 RG 从 0～1 解码到 -1～1，补零得到切线空间向量，用 TransformVector 从 Tangent 转到 World。随后与宏观世界法线正交化。如果材质启用了 Tangent Space Normal，输出到 Tangent 输入前再转回与材质设置一致的空间；切勿把世界空间向量直接当切线空间输入。

```hlsl
// 输入：DirectionWS、NormalWS；输出：单位世界空间切线。
float3 N = NormalWS / max(length(NormalWS), 1e-6);
float3 T = DirectionWS - N * dot(DirectionWS, N);
float3 axis = abs(N.z) < 0.9 ? float3(0,0,1) : float3(0,1,0);
float3 fallback = cross(axis, N);
T = dot(T,T) > 1e-8 ? T : fallback;
return T / max(length(T), 1e-6);
```

法线必须是有效非零输入。Flow 解码接近零向量时，应回退到确定方向。镜像 UV 需要检查切线基和方向符号；不连续的方向场会让高光在接缝处折断。

各向异性支持受平台和画质档位影响。用目标设备确认效果后再依赖它，不要只在编辑器最高画质下验收。先测 0、正值和负值三种状态，核对当前引擎的轴向约定，然后再绘制生产方向场。

### 高光强不等于金属

尼龙、氨纶等常见纤维属于非金属。光泽可以来自更低的粗糙度、定向微结构、灯光形状和表面整理，不需要 Metallic = 1。把非金属改为金属，会错误地改变漫反射和反射颜色。

亮片或金属纱确实可以包含导体，但应由局部遮罩选中。涂层可考虑额外反射瓣或涂层结构；Clear Coat 不是“丝袜专用开关”，启用前需要确认角色设定真有连续涂膜。

## 08 / 六组实操案例：每次只增加一个复杂度

下表是**艺术起始参数**，不是材料测量数据，也不与 D 数一一对应。颜色写为线性 RGB，`C` 表示平均覆盖。先在相同曝光和光照下比较，再迁移到角色。

| 案例 | YarnColor | C | TauRGB 基值 | Roughness | Anisotropy 起点 | 路线 |
| --- | --- | --- | --- | --- | --- | --- |
| A 薄透黑 | 0.016 / 0.020 / 0.027 | 0.65 | 0.28 | 0.44 | 0.25 | Opaque |
| B 裸色薄袜 | 0.50 / 0.29 / 0.19 | 0.60 | 0.20 | 0.50 | 0.15 | Opaque |
| C 半透白 | 0.78 / 0.80 / 0.85 | 0.80 | 0.55 | 0.62 | 0.10 | Opaque 起步 |
| D 厚织黑 | 0.018 / 0.023 / 0.029 | 1.00 | 3.00 | 0.80 | 0.05 | Opaque |
| E 光泽黑 | 0.010 / 0.013 / 0.020 | 0.80 | 0.80 | 0.23 | 0.45 | Opaque，各向异性 |
| F 菱形网 | 0.018 / 0.020 / 0.025 | 由孔洞决定 | 纱线本体可不透 | 0.50 | 0.20 | Masked 袜壳 |

### A / 黑色薄透：先保留肤色，再收轮廓

用第 06 节完成平滑表面。固定 C，只调 Tau，直到正面仍保留底层肤色；再检查接近轮廓的位置是否过黑。若轮廓形成生硬描边，先提高 MuFloor 或降低光学厚度，不要立即模糊整张底色。

增加针织 Density 的弱变化，例如把纹理映射为 0.85～1.15 的倍率。微法线只应在近景帮助读出织感，不应让整条腿像砂纸。最后检查膝盖和小腿侧面，宏观曲率必须仍可读。

### B / 裸色薄袜：在不同肤色上验证

同一份 YarnColor、C 和 Tau 应分别叠加在浅、中、深三种皮肤上。裸色纱线不会自动与所有皮肤“隐形匹配”。不要为了匹配一张截图，把最终袜色直接烘成固定肤色。

用区域遮罩控制袜口和脚尖；不应在所有裸露皮肤边界产生一条黑边。若皮肤本身含 AO、腮红或阴影烘焙，需要先理清哪些属于颜色，避免袜材质再次加深同一细节。

### C / 半透白：检查纱线自身的亮度

增加白色纱线的贡献后，仍保持底层肤色可见。只用低透明度白色混合，常会得到不自然的灰膜；应分别观察直射、环境和背光下的变化。

若需要突出独立皮肤散射与白纱反射，转到高级分层路线。不要把单表面颜色近似无限复杂化，直到调参无法解释。

### D / 厚织与绒感：降低透肤的存在感

提高密度和覆盖，让皮肤主要只影响少量残余颜色。提高粗糙度，使用低幅度织纹。需要绒面时，评估 Cloth 或 Substrate Fuzz，而不是添加一圈恒定发光的 Fresnel。

厚袜的褶皱、袜口和脚踝堆叠比“透明度”更重要。优先让网格和法线表达厚度，再决定是否增加绒毛层。

### E / 亮丝：用长条灯辨认方向

先关闭 Bloom，在暗一些的中性环境里用长条 Rect Light 检查高光。逐步降低粗糙度，再增加适度各向异性。交换横向和纵向 Flow，对照高光是否随之改变。

如果降低粗糙度后只剩一个刺眼白点，先检查灯源大小、方向场、法线和曝光。不要靠 Emissive 把高光画成长条。亮丝在环境光下也应有合理反射，不能只在一盏“专用灯”下面成立。

### F / 网袜与蕾丝：建立真正的孔洞

保留皮肤，套上蒙皮袜壳。先使用低频网格，使线宽至少有数个屏幕像素，再加入真实目标频率。检查前后腿交叠时，孔洞是否露出正确表面；检查袜壳是否给皮肤投下过重的摩尔阴影。

蕾丝分为花纹实面、连接细丝和孔洞三部分。花纹实面可用较厚的织物参数，连接线可使用更细法线；两者不必共享同一粗糙度。近景粗线补几何，远景合并成平均覆盖，避免把细线一直推给 Masked 阈值。

## 09 / 程序网格：导数必须在 frac 之前求

设连续坐标 `P` 表示周期数，线宽 `Duty` 表示一个周期中纱线占据的比例。这里的周期不是厘米；若圆柱周长为 L，想要单元宽度为 s，就应让周向周期数约为 `L / s`，并检查 UV 拉伸。

下面的 Custom 节点输出 Float 2：R 是过滤后的覆盖，G 是像素足迹大小。输入为 `P`（float2）和 `Duty`（float）。代码中 `P` 可以是 `UV * Tiling`；菱形网则可设为 `(U+V, U-V) * Tiling`。

```hlsl
float d = clamp(Duty, 0.001, 0.999);
float2 w = max(abs(ddx(P)) + abs(ddy(P)), 1e-5);
float2 lo = P - 0.5 * w;
float2 hi = P + 0.5 * w;
// 周期脉冲的原函数：floor(x)*d + min(frac(x), d)
float2 Ilo = floor(lo) * d + min(frac(lo), d);
float2 Ihi = floor(hi) * d + min(frac(hi), d);
float2 a = saturate((Ihi - Ilo) / w);
float coverage = 1.0 - (1.0-a.x) * (1.0-a.y);
float meanCoverage = 1.0 - (1.0-d) * (1.0-d);
float footprint = max(w.x, w.y);
float fade = smoothstep(0.75, 2.0, footprint);
return float2(lerp(coverage, meanCoverage, fade), footprint);
```

这段代码对各坐标轴上的周期脉冲做区间积分，再组合两组线。对轴向矩形足迹，它能准确表达相应的条纹平均；旋转、剪切和菱形变换后的真实屏幕足迹通常是平行四边形，这个分离估计并非严格的二维解析积分。远处回归平均覆盖可以提高稳定性，但不能把它描述成任意视角的完美过滤。

特别注意：`ddx(frac(P))` 会把周期跳变也当成导数，边界附近容易出现异常。应从连续的 P 求导。该函数使用屏幕导数，只能在支持导数的像素阶段使用，不要接到顶点位移或不支持的计算上下文。

### 覆盖平均值不能直接当作 Masked 的万能远景答案

如果线宽 Duty 为 0.16，两组正交线的平均覆盖为 `1 - 0.84² = 0.2944`。当 Opacity Mask Clip Value 大于这个数时，远景一旦收敛到均值，整片袜壳可能消失。

所以，**过滤后的平均覆盖适合颜色合成，不会自动变成正确的二值裁剪**。Masked 的远景需要经过验证的 Alpha-to-Coverage、时域覆盖策略，或直接切换到烘有平均网纹效果的身体 Opaque LOD。最后一种通常更容易控制，但必须同步处理袜壳隐藏与身体材质替换，避免过渡瞬间叠加变黑。

## 10 / Substrate：把纱线层与皮肤层分清楚

Substrate 的价值是更明确地表达材质结构，但并不是打开开关就得到更真实的丝袜。先决定你需要的是**区域混合**还是**上下分层**。

一个像素中，一部分面积是裸露皮肤，另一部分是纱线覆盖，这属于覆盖混合；光先经过纱线介质，再到皮肤反射回来，则属于纵向层次。这两种结构不能互相代替。

### 建议从两个可比较的版本开始

第一版保留本文 Opaque 的有效颜色近似，把结果接入单个 Slab，用 Roughness、Anisotropy 和有效 F0 控制反射。它适合验证迁移后是否保持原有艺术效果。

第二版才建立分层实验：

1. 建立底层皮肤 Slab，先用简化皮肤响应；确认所选平台是否支持需要的 Diffusion 行为。
2. 建立上层纱线 Slab。上层若要传输光，不能保持完全不透明的介质设置；为其设置可解释的厚度与平均自由程。
3. 用 Vertical Layer 将纱线放在皮肤上方。上层介质使用适合纵向层次的 Simple Volume 行为，并检查节点实际采用的散射类型。
4. 对存在可见孔隙的有效表面，用 Horizontal Mix 在“裸皮肤”与“纱线覆盖皮肤”的分支间按覆盖混合。务必看节点的背景/前景与混合权重说明，先用红蓝测试确认 0、1 的端点。
5. Front Material 连接最终 BSDF，检查 Slab 数量、编译统计、当前 GBuffer 模式和目标平台是否发生简化。

这些步骤定义了结构，不保证任意版本与平台都能保留相同层数。Blendable GBuffer 会倾向于合并到受限表示；Adaptive GBuffer 允许更复杂结构，但带来不同成本和平台要求。应分别检查调试视图，不能只看图上有两个 Slab 就认为运行时一定保留两套独立响应。

在纯吸收的简化关系中，光学厚度与厚度、平均自由程可以写成 `Tau ≈ Thickness / MFP`。这适合检查量纲，不代表把本文 Tau 直接填进所有 SSS 输入就能得到同样颜色；一旦加入散射，反射与透射的关系就更复杂。

传统 Material Layers 主要进行参数组织和混合，不等同于上述物质层叠。为了方便材质实例管理而建立的“皮肤层”“丝袜层”，也不自动意味着物理上有两层 BSDF。

## 11 / 接缝、袜口、脚尖与局部加固

先建立区域权重，再分别改变结构参数。一个加固遮罩 `R` 可以控制 `Tau *= lerp(1, ReinforceScale, R)`；袜口折叠也可能需要独立几何厚度，而不只是把 R 涂白。

| 部位 | 首先处理 | 再考虑 | 不建议的捷径 |
| --- | --- | --- | --- |
| 袜口 / 松紧带 | 几何厚度与织密区域 | 不同纱线、高光方向 | 画一条纯黑横线 |
| 后中缝 | 线宽、高度、连续 UV | 缝线粗糙度和方向 | 仅用很强 AO |
| 脚尖 / 脚跟 | 局部光学厚度、版型 | 法线与缝合区域 | 整片染成与身体无关的黑块 |
| 膝盖拉伸 | 密度变化和 UV 拉伸 | 细纹方向、局部粗糙度 | 只提高透明度 |
| 脚踝堆积 | 真实褶皱或受控法线 | 折叠处覆盖与遮挡 | 在底色烘死阴影 |
| 连裤加固区域 | 独立区域参数与连接结构 | 接缝、厚度变化 | 全身共用一张均匀平铺图 |

皮肤 AO、袜壳 AO、接缝 AO 可能描述同一遮挡，不应全部相乘。先观察引擎实际阴影，再决定纹理里保留多少低频遮挡。

## 12 / 拉伸、湿润、破损与特殊材质

### 拉伸改变的不是一个透明度数字

织物拉伸会改变单位面积纱线分布、孔隙形状和方向。一个可控制的近似是根据静止与变形面积比 `AreaRatio` 降低密度，例如 `DensityScale = clamp(1 / AreaRatio, 0.5, 1.5)`。上下限是艺术保护，不是弹性力学常数。

AreaRatio 可以来自离线区域绘制、骨骼驱动或布料系统输出。普通材质 UV 并不会自动携带真实应变。用屏幕导数估计面积时，还混入投影与可见性因素，不能直接把它当成物理拉伸率。

拉伸时不宜让网孔保持完全正菱形；方向场、线宽和法线频率应一起检查。英雄近景需要可靠模型或织物变形数据，单靠噪声无法补足结构。

### 湿润需要建立空间分布

湿润可能改变纱线和空气之间的界面、局部反射及有效透射。工程上可让 WetMask 控制粗糙度下降、颜色或吸收变化，以及必要的水膜反射，但变化方向取决于材料和照明，不能规定“所有湿袜都必定更黑更透明”。

把大面积湿区、边界和离散水滴分开。水滴如果可见轮廓和明显折射，属于另一层资产；不要为了几个水滴，让整条腿变成高成本透明材质。

### 破洞与抽丝是两个尺度

破洞改变覆盖和轮廓，近景可通过真实几何、Masked 或独立破损片实现。抽丝改变针织结构，常形成沿线圈方向延伸的细线与稀疏区。只叠一张随机裂纹法线，通常不像织物损坏。

Opaque 身体合成上的破洞可让区域回到裸皮肤参数。独立袜壳的破洞则应切掉袜壳，并保证皮肤还在。若删除了底层皮肤来省面数，破洞就会看穿角色。

### 金属丝、珠光与涂膜

金属纱使用局部导体参数；珠光或薄膜干涉需要额外光学模型，普通彩色高光只是艺术近似。亮片在像素以下时需要稳定的统计反射，不能每帧随机选亮点。除非项目确实需要这些材质，先把它们作为独立变体，不污染基础袜材质的参数。

## 13 / 远景过滤：先稳定信号，再稳定历史

细织纹可以在近景清晰、远景平均，但不能在远景仍以无限锐利的方式存在。设一个像素跨过的织纹周期数为 footprint：很小的时候可以保留结构；接近或超过一个周期时，应逐步回到有效覆盖和有效粗糙度。

纹理 Mip、各向异性过滤和程序导数都在解决像素足迹问题。三者不是互相排斥的选项：普通织纹用正确 Mip，斜视角改善纹理采样，程序网格使用解析近似，极远处交给更简单的材质表示。

微法线变平后，消失的方向变化不应全部变成镜面。可以使用 Normal-to-Roughness / Composite Texture 思路，让高频法线方差影响粗糙度 Mip。具体资产设置在不同版本中可能变化，必须检查生成后的各级 Mip，而不是仅勾选一次就结束。

Alpha 覆盖保持也需要看实际阈值：普通平均 Mip 可能让 Masked 纱线整体变细或消失；保持覆盖的处理则可能改变局部线宽和对比度。近景高质量并不等于远景仍然逐根可读。

### 以屏幕尺度驱动 LOD

| 屏幕状态 | 表面表示 | 微法线与方向 | 过渡要求 |
| --- | --- | --- | --- |
| 线宽明显大于 1 像素 | 可读织纹、近景网线 | 保留有意义的细节 | 检查透视与 UV 拉伸 |
| 线宽接近 1 像素 | 过滤覆盖，降低高频对比 | 增加有效粗糙度 | 缓慢移动相机观察闪烁 |
| 多根纱线落入 1 像素 | 平均光学参数 | 使用低频方向与粗糙度 | 袜壳与身体 LOD 协调 |
| 角色只占少量屏幕空间 | 简化身体材质 | 移除无贡献采样 | 保留整体轮廓和区域分组 |

表格是尺度原则，不是通用距离表。4K 与 1080p、不同 FOV、动态分辨率都会改变同一距离对应的像素尺寸。

## 14 / TAA、TSR、MSAA 与透明速度

时间抗锯齿可以整合历史，但无法挽救完全错误的输入频率。先关闭材质微细节验证几何和速度，再逐项打开织纹、方向性高光和透明层。

透明像素可能叠着多个不同深度与速度的表面，历史重投影却无法为每一层保留独立的信息。在需要的材质上评估 Output Depth and Velocity，并配合合适的写入门槛；门槛过低也可能覆盖后方物体本该使用的深度和速度。

材质中的动画 WPO 需要正确的前帧数据。Previous Frame Switch 可以为相应参数提供上一帧值，但它不能自动修复错误的骨骼速度或所有 UV 动画。

透明渲染在景深前后的位置会影响外观和重建。不要把切到 Before DOF 当作通用去拖影开关；必须同时检查景深轮廓、背景与透明交叠。

传统 Forward Renderer 可以结合 MSAA 和 Masked 的 Alpha-to-Coverage，但它与 Deferred 的功能和成本不同。MSAA主要改善覆盖，不会自动消除着色内部的高频法线与高光闪烁。不要只为一件袜子就切换整个项目渲染器。

## 15 / 写实与卡通：共享结构，分开光照风格

卡通角色同样需要覆盖、密度和方向场。可以简化光照，但最好保留这些结构参数，使材质在相机旋转和姿态变化时仍然一致。

对于已有卡通渲染框架的项目，把纱线与皮肤的有效颜色送入其漫反射分层，在高光阶段使用独立的宽度和方向控制。明暗分界应受到光照与阴影可见性的约束，不应只根据相机方向变化。

如果项目没有自定义 Shading Model，使用 Unlit 加手动 `N·L` 可以做教学预览，但不会自动取得整套动态灯光、投影阴影和环境反射。把所有计算写进 Emissive 并称为“完整 UE 卡通管线”，会掩盖这些缺失。

实际可选方案是：使用项目现有卡通框架；在 Default Lit 上做受控艺术化材质；或明确承担引擎修改成本，扩展着色模型并验证 GBuffer、灯光、阴影和平台编译。本文的 Custom 节点只计算材质输入，不修改 UE 的光照积分。

卡通高光可以比写实更宽、更整洁，但别同时叠加自绘高光和同等强度的引擎镜面反射。亮部容易因此失去层次，丝袜和皮肤也会变得无法区分。

## 16 / 完整帧管线：材质处在哪一段

对于常见 Deferred 场景，可以按下面的依赖理解；它不是所有 UE 配置下固定不变的执行顺序。

```text
模型 / 蒙皮 / UV / 材质参数
    ├─ 深度、速度与阴影相关阶段
    ├─ Opaque / Masked：表面属性 → GBuffer → 光照 / 散射
    └─ Translucent：单独的透明着色与合成路径
                 ↓
        与配置相关的景深、时间重建及其他后处理
                 ↓
             色调映射与最终显示
```

袜子出现问题时，先定位发生在哪一段。颜色不对看线性空间和合成；高光方向不对看切线；孔洞不对看覆盖与深度；运动拖影看速度和历史；过曝看光照及后处理。不要遇到任何问题都回到 Roughness。

## 17 / 光照标定与验收镜头

建立一个固定曝光的中性测试场景，保存六个镜头：正面、三分之二侧面、掠射轮廓、膝盖近景、脚踝接缝、全身远景。先关闭自动曝光和强烈调色；对比时保持相机、分辨率与灯光强度一致。

第一盏灯用于看漫反射和形体；一盏较长的矩形灯用于读高光方向；环境光用于检查没有强主灯时是否还能识别材质。之后再加入背光和复杂场景，而不是从霓虹环境里开始盲调。

动态验收至少包含相机横移、角色转身、走路、交叉腿部、蹲起和 LOD 切换。每次先回放正常速度，再逐帧看问题，避免只选一张最好看的截图。

| 测试 | 应看到什么 | 失败通常指向 |
| --- | --- | --- |
| C 设 0 | 恢复同一底层皮肤颜色 | 合成权重错误 |
| Tau 设 0 | 没有吸收贡献 | 通道或指数方向错误 |
| 相机转动，灯不动 | 密度随视角连续变化 | 宏观法线、边缘项 |
| 灯转动，相机不动 | 高光跟随照明变化 | 烘死高光、错误 Tangent |
| Flow 旋转 90° | 方向性响应改变 | 空间转换、各向异性未启用 |
| 替换深浅肤色 | 同一纱线仍保留合理底层差异 | 固定袜底色掩盖皮肤 |
| 相机慢慢拉远 | 织纹趋向稳定平均 | Mip、阈值、材质频率 |
| 双腿交叠 | 正确皮肤与袜层遮挡 | 排序、穿插、深度写入 |
| 关闭微法线 | 高频闪烁应明显改变 | 镜面混叠而非轮廓锯齿 |
| 切换目标画质档 | 退化受控、没有突然失真 | 平台功能或 LOD 缺失 |

## 18 / 性能预算：记录可比较的增量

没有目标设备、分辨率和镜头，就没有有意义的“丝袜材质耗时”。先保存裸皮肤基线，再依次开启颜色合成、织纹、各向异性、袜壳和透明分层，观察增量。

| 变体 | 记录项 | 主要风险 |
| --- | --- | --- |
| 身体 Opaque 合成 | Base Pass、材质采样与像素成本 | 高频纹理过多 |
| Masked 袜壳 | 深度、阴影、Base Pass、覆盖 | 额外几何和像素工作 |
| Translucent | 透明阶段、灯光与屏幕覆盖面积 | Overdraw、逐灯计算、排序 |
| 多 Slab Substrate | 实际保留结构、带宽、着色耗时 | 平台简化与复杂度成本 |
| 网袜近景几何 | 蒙皮、三角形、阴影与 LOD | 曲面细线数量过大 |

使用 `stat gpu` 和 GPU Visualizer / `ProfileGPU` 定位阶段，同时记录硬件、RHI、UE 版本、输出分辨率、Screen Percentage、抗锯齿模式、角色屏幕占比、灯光数量和样本次数。编辑器与打包版本结果分开记录。

比较时使用同一稳定回放，先预热，报告多次样本的中位数及波动，而不是只截取最小值。下载包中的 CSV 是空白记录模板，未填入任何虚构 GPU 数据。

## 19 / 常见故障的最短排查路径

| 现象 | 先做的检查 | 对应修正 |
| --- | --- | --- |
| 像塑料 / 乳胶 | Metallic、过低粗糙度、缺少结构 | 非金属起步，恢复纱线方向与合理反射宽度 |
| 边缘一圈死黑 | Tau 与 EdgeDensity 是否重复 | 单独关闭两项比较，再调 MuFloor |
| 白袜像灰玻璃 | 是否只在做透明混合 | 补纱线反射，必要时分层 |
| 膝盖脏斑 | 密度是否使用高频法线 | 分离宏观法线与微法线 |
| 高光在接缝折断 | Flow、镜像 UV、空间转换 | 检查切线基并重绘方向过渡 |
| 远景网袜消失 | 平均覆盖与 Clip Value | 协调 Opaque 远景替代与袜壳 LOD |
| 移动时亮点闪烁 | 法线方差、低粗糙度、频率 | 预过滤并提高有效粗糙度 |
| 透明袜拖影 | 深度 / 速度、动画、交叠 | 逐项检查速度输出与透明路径 |
| 角色轮廓双边 | 袜壳间隙和底层轮廓 | 减少不必要壳层，修正蒙皮 |
| 暗部越来越黑 | AO、密度、阴影重复叠加 | 拆开各贡献，按单项验证 |
| 低画质高光变圆 | 各向异性支持与材质简化 | 准备低档可接受的粗糙度变体 |
| 调参只对一个角度有效 | 光照或颜色烘焙过重 | 回到中性场景进行多角度标定 |

## 20 / 练习包的使用顺序

先下载 [UE Hosiery Kit](/downloads/hosiery/ue-hosiery-kit.zip)，按 README 导入贴图并创建材质。包内的三个 `.hlsl` 文件是 Custom 节点函数体；不包含 `.uasset`、角色模型或已编译的 UE 工程。

1. 用 `HosieryColor.hlsl` 在圆柱上完成薄透黑基线，验证 C 与 Tau 的端点。
2. 接入 `SafeTangent.hlsl`，先看常量方向，再看 Flow 贴图。
3. 建立保留底层皮肤的 Masked 袜壳，测试 `FilteredGrid.hlsl`；不要跳过远景阈值问题。
4. 导入针织、蕾丝和加固贴图，分别制作六组实例；区域 UV 需要自己适配角色。
5. 按第 17 节保存静态与动态对照，再使用性能模板记录实际结果。

`verify_math.py` 检查透射端点、角度单调性、数值有界、方向正交化与周期覆盖积分。它验证的是数学部分，不替代 UE 编译、渲染路径支持或真机验收。`generate.py` 保留图表和纹理的构造过程，方便改变分辨率与结构参数重新生成。

材质做到可控的标准，是每个参数都有明确职责：覆盖决定露出多少，光学厚度决定吸收多少，方向与粗糙度决定怎样反光，几何决定实际层次，过滤决定远处如何稳定。沿着这条顺序，增加新的袜类变体就能成为有依据的组合，而不是不断堆叠无法解释的效果。
